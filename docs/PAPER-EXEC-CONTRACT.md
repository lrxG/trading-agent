## 一、目标的可验收定义（把"长期赚钱"翻译成判据）

| 判据 | 门槛 | 为什么 |
|---|---|---|
| 滚动 12 个月净值 | **> 0** | 用户底线："一年一个点就是成功" |
| 最大回撤 | **< 15%** | 与 params 熔断 L1 对齐；回撤决定能否活到长期 |
| 单笔最大亏损（占总权益） | **≤ 2%** | 单笔不致命才能谈长期 |
| 年交易笔数 | **≥ 30** | 低于 30 笔的"正收益"是运气，不可信 |
| 每笔可追溯 | **100%** | 必须有 decision_id + C4 依据 + C5 批准记录 |

**风险调整优先于收益**：Calmar（年化/最大回撤）是主排序指标，不是收益率。
现状对照：V6c 17.1%/MDD 4.9% ⇒ Calmar ≈ 1.3（样本仅 18 笔，证据不足）；
V8 25.4%/MDD 15.1% ⇒ Calmar ≈ 0.63（样本 112 笔，证据强）。
**⇒ 结论：主仓倾斜 V6c 族的低回撤结构，V8 只做卫星；第一优先是扩样，不是选冠军。**

## 二、三条硬性自律（无人监督时更要守）

1. **无 decision_id 不下单**。任何模拟盘委托必须先有 C4 三问落账 + C5 批准的 RISK_PLAN；
   禁止"感觉这票要涨"下单。违者即绕过门禁 = 自己给自己开后门。
2. **交易频率上限**：每周新开仓 ≤ 3 笔，同时持仓 ≤ 3（params.max_holding_count）。
   纸面盘最大陷阱是无限资金 + 无心理压力 ⇒ 过度交易。频率上限是唯一解药。
3. **周度双跑对账**：同一批决策在官方模拟盘与自研 replay 各跑一遍，比成交价/费用/拒单；
   偏差 > 0.5% 即停手查撮合口径，不允许"两边都跑、只报好看的那个"。

## 三、模拟盘的三个用法（不是"玩"）

| 用法 | 补什么洞 | 优先级 |
|---|---|---|
| **撮合口径校准** | replay 的 T+1 开盘、涨跌停拒单、费率全在自证，无外部基准 | P0 |
| **多策略并行小仓位实验** | 回测冠军在真实撮合下可能崩（V8 依赖精确成交，滑点敏感）；用真成交淘汰假冠军 | P1 |
| **唯一真实记账的净值曲线** | decision_ledger 至今零 BUY、capital=0 | P1 |

## 四、纸面盘的三个失真（必须打折，不许当实盘结论）

1. **限价单可能不成交** → 纸面成交概率被高估 ⇒ 策略收益偏乐观；实盘可用市价单但吃滑点
2. **无资金心理压力** → 纸面能扛 15% 回撤，真人可能 8% 就砍；回测/纸面的持有期假设偏乐观
3. **无冲击成本** → 小资金纸面盘不吃冲击；资金变大后衰减不可测

⇒ 因此：**策略层经验可用，执行层经验打折，心理层经验为零**。

## 五、失败的定义（比成功更重要）

- 连续 20 笔滚动净期望 95% CI 上界 < 0 ⇒ 策略判死，停止该策略族（不是调参救）
- 累计回撤触 L2（25%）⇒ 全停，回到研究态重新校准阈值，禁止"加仓扳回来"
- 单笔亏损 > 2% 权益 ⇒ 记录为执行事故，查是决策错还是执行错（拒单/滑点/未按计划止损）

## 二·五、MANUAL_OVERRIDE 例外（2026-10-28 新增）

**背景**：2026-10-28 出现首例人工建仓（`OVR-20261028-001`，736 股国债 ETF）。
根因不是绕过契约，而是 C5 资金闸因 `params` 缺键而必然 fail-closed，决策链无法产出 BUY。
若不允许例外，则「框架有缺陷时只能空仓看」——这本身是风险。

**允许条件（全部满足才成立）**：
1. 决策链因**已登记的技术缺陷**（非策略判断）无法产出合法 BUY；
2. 该笔必须有 `decision_kind="MANUAL_OVERRIDE"` + `decision_ref="OVR-YYYYMMDD-NNN"`；
3. 必须补 `risk_plan`（入场依据 / 退出条件 / 止损 / 复核频率），缺一不可；
4. 必须标 `slot_counted=false`，且**不得并入** `decision_ledger.jsonl`；
5. 在 `memory/state/positions.md` 登记，并写明根因与修复状态。

**强制退出**：根因修复后，下一个决策周期起不得新增 MANUAL_OVERRIDE；存量须在环境切换时清理。
**审计口径**：MANUAL_OVERRIDE 占比 > 20% 或连续 2 周存在 ⇒ 视为流程失效，须停手整改。
