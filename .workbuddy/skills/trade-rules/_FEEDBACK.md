# 交易规则反馈层（_FEEDBACK.md）· 核对 → 统计 → 修订

> **结构**：规则层（`SKILL.md`）+ 反馈层（本件）。**无独立数据层**——证据引用权威源，核对结果记于本件，数据本体不落此处（防重复存储）。
> **反哺唯一路径**：案例 → 核对规则命中 → 统计 → 反例达阈值 → 修订建议 → **人审** → 更新规则层（记版本）。**禁手动改规则绕过证据层**（用户红线）。
> **修订阈值（新系统口径）**：`params.rule_decay_refute_streak = 2`（连续 2 次反例即触发修订建议）——**旧件写的是"连续 3 次"**，本件采用新系统值。
