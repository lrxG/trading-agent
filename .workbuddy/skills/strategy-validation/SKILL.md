# 策略验证协议（strategy-validation）

> 本 skill 解决一件事：**避免把"在历史数据上表现最好的做法"当成"规律"。**
> 实测依据：220,798 个样本、10 个季度 fold，用训练窗挑最优组合、验证窗实测，进前 3 名的比例 **0/7**（随机基线 7%）。挑出来的"最优"，下一期平均排到倒数。**选择本身不产生信息。**

## 一、什么时候必须走这套协议

- 从盘面观察出某种"形态好像有效"（如：缩量回调会涨、二板接力能赚、跌破均线该走）
- 要把一条经验写进 `.workbuddy/skills/*/SKILL.md` 或 `calibration_queue`
- 用户问"这个战法灵不灵"、"验证一下"

**不走这套的后果**：写进规则库的是过拟合产物，下次执行时按错的做，且看起来有数据支撑——比没数据更危险。

## 二、三步走（缺一步即未完成）

### 第 1 步 · Observation：落脚本

产物落 `data/research/obs/obs_{日期}_{主题}.py` 或 `bt_{日期}_{主题}.py`。

脚本必须满足六条形式要求（每条都可机械检查）：

| # | 要求 | 为什么（可验证的后果） |
|---|---|---|
| 1 | 样本区间写成顶部显式常量（`START = "2024-01-01"`），输出首行打印区间与样本量 | 区间混入 2025-08 前数据会有选择偏差（当时每日只覆盖约 2530 只，非全市场） |
| 2 | 涨跌幅用 `change_pct` 累乘重建，不用 `close` 相除 | `close` 不复权；除权票 60 日跌幅可虚高 31.8 个百分点 |
| 3 | 所有入场特征用**入场日可见**的量；未来数据一律不进特征列 | 特征列混入未来量，回测收益直接虚高且无法察觉 |
| 4 | 逐日横截面构造对照基准（同日全市场同期收益），不跨期比 | 跨期比会把 beta 当成 alpha；2024Q3 与 2026Q2 的市场方向完全相反 |
| 5 | 连续计数用「非条件日切段」，不累加 | 累加算的是历史总量，不是当前连续段长 |
| 6 | 剔除 ST / 北交所 / 上市不满 60 交易日 / 低价（<3 元） | ST 限幅口径失真；次新股污染；低价股博弈性质不同 |

### 第 2 步 · Verification：步进式检验

按季度切 fold，**训练窗只用于选，验证窗才是成绩单**。骨架（可直接复制改）：

```python
FOLDS = 按季度分组(rows)                       # 每 fold ≥200 条样本
for i in range(3, len(FOLDS)):
    train, valid = FOLDS[i-3:i], FOLDS[i]      # 训练 3 个季度，验证下一季度
    best = argmax_均值(train, 全部候选组合)      # 只读训练窗
    record(valid_表现(best), valid内排名(best))  # 打开验证窗
```

同时必须做**不用选择的对照**：固定用某条组合，跑完所有验证窗，报均值与最差 fold。
因为选择无效时，唯一可用的是"先验设定、固定使用"的那条。

### 第 3 步 · 定级：按三条判据决定去向

| 判据 | 通过线 | 去向 |
|---|---|---|
| **跨 fold 符号一致性** | ≥7/10 个 fold 同号 | 必要条件，不满足直接留在 obs 层 |
| **最差 fold 不失控** | 最差单 fold 中位亏损 ≥ −8% | 满足才可作**执行规则** |
| **验证窗不劣于对照** | 与固定使用同一组合的验证均值差 ≥ 0 | 满足才可作**优选规则** |

三条全过的 → 写成规则（skill 章节 / `calibration_queue` 候选，后者仍须用户批准）。
过 1~2 条的 → 记为「有线索、未定型」，留在 obs，标注缺哪个判据。
一条不过 → 在 obs 里标「已否证」，附否证数据。

## 三、报告必须给的五个数（缺一即不完整）

用户口径（2026-11-05 定）：目标是抓到区间涨幅最大的票，**胜率与 T+N 平均涨幅不作为评价标准**。

| # | 数 | 说明 |
|---|---|---|
| 1 | **区间最大涨幅分布** | 中位 / P90 / P99 —— 右尾有多厚 |
| 2 | **先套深度** | 买入后 10 日 / 20 日内最深浮亏的中位 —— 能不能拿住 |
| 3 | **赔率** | 中位最大涨幅 / 中位先套深度 |
| 4 | **赚 30%+ 与亏 10%+ 占比** | 两端概率，右尾策略靠这个算期望 |
| 5 | **fold 一致性 + 最差 fold** | 上面三条判据的原始读数 |

**均值单列不算结论**：右尾分布下均值被少数样本主导，中位与分位数才是可用读数。

## 四、四条铁律（每条都有实测支撑）

1. **规则先验设定、固定使用**。不在历史段上挑"哪条最好"，挑优迁移率 0/7。
2. **出场规则按入场口径配对**。跌破 MA5 在「深跌入场」上 10/10 fold 为正（最稳防守）；在「已涨大牛股」上把捕获率从 54% 砍到 0.1%。同一规则跨口径会反向。
3. **样本量先看再下结论**。n<100 的格子只当线索；n<20 一律写「样本不足」，不硬测。
4. **结论必须带边界**。写明市场（A 股）、区间、含什么特殊阶段（如 924 反弹）。跨市场不自动成立。

**负面结论（11-09 新增 · 自己建的工具自己验伪）**

- **「名称族封板率在聚」信号无效。** `tools/analysis/zibei_thermo.py --verify`，2026-09-01~11-06 / 43 个交易日 / 252 个族-日：T+1 超额 +0.290% 但按日聚类 **t=−0.15**、日胜率 45.0%；仅双字族 T+3 超额 **−0.011%**、胜率 38.7%。**t 贴近 0 + 胜率不过半 = 统计上等于零，不可用。** 结论：族温度计只能描述当日状态，不能当买点。
- **「族」的自动挖掘会把行业词当族。** 43 天挖出的族里大量是「健康/制药/医药/光电/传媒」，名称族与行业族在程序层无可靠分离手段：`stock_industry.json` 是三级细分代码，「东方」27 只跨 24 个代码、单字「方」65 只跨 42 个 —— 阈值怎么调都判不出。**已放弃自动判别，改为原样列出涨停票行业名由人判断。** 教训：**一个判据如果调任何阈值都分不开两类，说明这个判据本身选错了，不是阈值没调好。**

**口径边界（11-06 新增，必读）**：
- **★反应日必须是「披露日 D」，不是 D+1（11-09 实证，偏差方向性）**：第一版把披露日当「公告日」、D+1 当反应日，得出「次日上涨占比 47.6% = 随机基准，无任何 alpha」的**错误结论**。实测 D 日开盘跳空均值 +1.36%（停牌型 +3.07%）——若公告是当晚才发，开盘不可能跳空，说明**开盘前公告已公开**。按 D+1 算会整段丢掉「公告日已涨」。
  残留偏差：若公告在 D 日盘中发布，D 日开盘买入含未来信息；但开盘跳空显著为正说明多数公告在开盘前公开，该口径对多数样本成立。要 100% 不含未来函数只能用 D+1 口径，代价是白丢一天涨幅（`ml_08_ma.py` 保留作对照）。
- **事件识别不能加「启动词」白名单（11-09 实证）**：用 `筹划/预案/意向/拟/暨` 过滤会滤掉「关于收购巴西 CSN CIMENTOS 股权的公告」这类真事件（标题不含任何启动词）。只用黑名单剔派生文件。修完后事件数 3,355 → 4,730、有效样本 2,208 → 3,085。
- **`df.sub` / `df.count` / `df.min` 等作列名会静默出错**：`df.sub` 是 DataFrame 的减法方法，`df.sub == "现金收购"` 恒为 False **且不报错**。ml_09 的组合矩阵因此静默输出「0 个组合中 0 个为正」，差点被当成「无存活子集」的结论。**写 `df["sub"]`，不要用属性访问。**
- **`klines.csv` 有 open<=0 的停牌脏行**（249 行），会让收益率爆成 inf，任何收益率计算前必须过滤。
- **★切格子找「唯一活着的格子」= p-hacking，必须做多重检验校正。** 11-09 实锤：我切 9 档×3 年 + 5 筛法×2，共几十个格子，报出「妖股区 2026 净 +0.41%」当成发现。做 Bonferroni（α=0.05/15=0.0033，|t|>3.02）后发现它 t=2.49 **未过校正**，而真正过校正的 6 个里 5 个是负的。**判据：报出任何「某个子档为正」之前，先报格子总数与校正阈值；没做校正的格子结论一律只能写成「待验」，不能写成「发现」。**
- **★收益归因必须做成可审计的恒等式，不能只说「高开吃掉了」这种话。** 三段分解 `total = (1+gap)(1+intra)(1+drift)−1`，其中 `gap=open[D+1]/close[D]−1` 是买入前已发生、`intra` 是买入当日日内、`drift` 是持有过夜。乘法链最大偏差 <1e-15 才算通过。**只有把「拿不到的部分」和「拿得到但亏的部分」分开算，归因才能变成动作**（例：涨停票 gap +2.19%、实得 −0.22% → 动作是「不追高开」，不是「涨停不好」）。
- **★★★「发现」和「获利」必须分开评估，否则会互相掩盖。** 11-09 实锤：10 月 49 只大涨票 88% 起飞日涨停、65% 进过涨停池 → **发现渠道覆盖 2/3 以上**；但同期 35,857 个涨停事件次开买 T+10 −1.15%、T+20 −2.05% → **全买必亏**。判据：①先报「能发现的比例」（信号覆盖率）②再报「全买的期望」③两者之差就是"筛选能力"要补的缺口；④若筛选特征 IC<0.1，说明缺口在个股维度补不上，必须转去时间维度（哪天）或结构维度（哪条链）。
- **★★★归因前必须穷举「分组方式」，不能默认行业。** 2026-11-09 实锤：10 月涨幅我先按通达信行业归因为「机器人链+传媒」，实际是「羊字辈」（洋/阳谐音族）；同一族被行业拆到 9 个板块（光学光电子/农林牧渔/渔业/家电/汽零/电机/通用设备…），行业维度结构性地看不见。**清单：行业 / 概念 / 地域 / 名称字与谐音 / 代码 / 股东 / 游资席位。其中「名称字辈」零数据成本、100% 事前可知，必须先测一遍。**
- **★★「事前不可分」这种否定结论，必须限定在已穷举的维度内。** 同一案子：我测了 p20/dd60/量比/成交额/20日位置 六个形态特征，就说「起飞前形态分不开 → 事前不可分」。但名称是静态字符串、9-30 就已确定，属于 100% 事前可分。**规矩：报"不可预测"之前先自问「有没有哪个维度是静态的、我还没测」。**
- **★★★策略评估必须先报「信号日占比」再报收益，因为日频满仓的复利会放大一切。** 11-09 实锤：S1 在 688 天里 626 天有信号（91%），单笔看着只是 −0.2%，2026 年复利 **−42.6%**。**判据：①报净值不只报单笔均值 ②报信号日占比 ③日均净 |x|<0.1% 一律判零 ④任何正收益必须先做「剔除最好 1~3 天」的集中度检验。**
- **★★★任何选股/事件信号必须按交易日聚类重算显著度，否则 t 值会被放大一个量级。** 11-09 实锤：形态④ 5,680 个样本只来自 120 个交易日（单日 47 只，2024-02 一个月占 41%），个股层面 alpha +1.49%/t=15.81，**按日聚类后 −0.80%/t=−1.51，符号翻转**。判据：**信号日数 < 样本数/10 时必须聚类重算**；同时报「个股层面 t」与「聚类 t」，两者符号不一致即判定为聚集假象。**本条使已入库的 S1~S5 与 ml_21 环境矩阵（均未聚类，ml_21 报过 t=27.3）全部降级为「待验」。**
- **★★绝对收益与超额收益必须分开报，且超额要分三层（市场/行业/个股）。** 11-09 实锤：行业崩组绝对 +2.31% 看着极强，减同日全市场中位后只剩 +0.28%，88% 是 beta。**判据：一个形态要算真 alpha，必须「超市场」与「超行业」同时为正；只报绝对收益的结论一律作废。**
- **★★禁止把不同环境的数据混在一起统计，这会系统性埋掉有效策略。** 11-09 实锤：同一套 S1 低位反弹，多头·普涨净 +1.79%(t=27.3)、空头·冰点 −0.29%，混合后只剩 +0.15%，我据此报了「2026 无任何方向为正」的假结论。**规矩：任何选票结论必须报「环境分档后」的数字；只报全局均值不足以判死一个策略。**
- **★★实现已验证条件时，禁止擅自加「看起来合理」的附加条件。** 11-09 实锤：`ml_19` 测的是「前20日跌>10% + 今日涨3~7%」，我在实现 `stock_pick.py` 时自作主张加了「量比≥1.5（放量确认）」，结果 2026 从净 **+0.15%** 变成 **−0.30%**，胜率从 51.1% 掉到 45.4%。做参数敏感性才发现量比是**单调负向**的。**规矩：落地代码必须与回测口径逐字对齐；要加条件，先单独跑该条件的敏感性，把结果写进结论库再改代码。**
- **归因必须单独剔除极端跳变**：`|单段收益|>150%` 的多为除权/退市整理，不剔除会污染均值与恒等式校验。

- **★前向收益的方向坑（11-06 一天踩两次，最贵的教训）**：`rolling(k)` 是向**后**看的窗口。写 `s.shift(-1).rolling(k)` 得到的是 `[t-k+2, t+1]`，与过去窗口重叠 k−1 天。实测：T+5 的「5日超额 → fwd5」IC 因此虚高到 **0.75**、胜率 100%（正常应 ≈ −0.05）。**正确写法 `s.rolling(k).shift(-k)`**。
  **自查方法**：算出 IC 后先看量级——日频横截面 IC 落在 ±0.15 之外，先怀疑泄漏，不要先怀疑「发现了强信号」。
- **前向收益必须去重叠**：T+k 的前向收益在相邻日上重叠 k 天，朴素 t 值虚高。主口径按每 k 日采样一次，重叠口径只作对照；两者差异大 = 把噪声当信号。
- **均值与中位必须同时给**：ML-4 各组 T+10 **均值全正、中位全负**（分布右偏），典型票是亏的，均值靠少数暴涨拉起。只报均值会系统性高估体验。
- **规则只能由步进式检验改，不能由单次结果改。** 11-06 实锤（我差点写反）：我早盘判贝特利「高换手+连续大涨=最后一棒」，当日它 +20% 封板。我随即在复盘里写下「这条错判」，并准备据此推出反向规则「小盘票涨幅不是风险」。**跑完 3.2 万样本才发现：原判断在统计上是对的（小盘连板赔率 0.50 vs 大盘 0.95），单次结果不构成否证。**
  这与 §R2「盘中禁改规则」是同一毛病的两面：R2 是**盘中用价格改规则**，这里是**盘后用单次结果改规则**。两者都是**用噪音改规则**。
  **可执行判据**：任何「我错了 / 这条规则不对」的结论，在写进文件之前必须先问一句——**是规则输了，还是这一次输了？** 答不出就只记录，不改规则。
- **检验设计本身要先检查指标是否退化**：v1 版我用「区间最大涨幅」算「亏15%+占比」——该指标天然 ≥0，导致亏损占比恒为 0、赔率恒为 inf，整张表无意义。**右尾指标与左尾指标必须用不同字段**（本版右尾用最大涨幅、左尾用末日收益）。
- 「我的持仓成本低于大单成本」与「现价低于大单成本」是两件事。前者是个人盈亏位置，**回测证明无信息量**；后者才是市场状态。用户混淆这两者是常见错误。
- VWAP20 是「大单成本」的代理，不是真实逐笔大单成本。本地 `fundflow.csv` 仅有 20 个交易日历史，不足以做长周期大单成本重建。
- **ST 过滤必须按股票级、不能按行级**：按行过滤会把改名股票（天际股份→ST天际）的价格序列截断在改名日，回测将使用改名前的旧价格。11-06 实锤：天际因此被错判为 A3 深套（现价 15.94/成本 35.48），修复后实为 B 组（11.74/11.65，站上 MA20）。
