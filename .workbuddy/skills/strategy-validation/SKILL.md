# 策略验证协议（strategy-validation）

> 本 skill 解决一件事：**避免把"在历史数据上表现最好的做法"当成"规律"。**
> 实测依据：220,798 个样本、10 个季度 fold，用训练窗挑最优组合、验证窗实测，进前 3 名的比例 **0/7**（随机基线 7%）。挑出来的"最优"，下一期平均排到倒数。**选择本身不产生信息。**

## 一、什么时候必须走这套协议

- 从盘面观察出某种"形态好像有效"（如：缩量回调会涨、二板接力能赚、跌破均线该走）
- 要把一条经验写进 `.workbuddy/skills/*/SKILL.md` 或 `calibration_queue`
- 用户问"这个战法灵不灵"、"验证一下"

**不走这套的后果**：写进规则库的是过拟合产物，下次执行时按错的做，且看起来有数据支撑——比没数据更危险。

## 二、三步走（缺一步即未完成）

### 第 1 步 · Observation：落脚本

产物落 `data/research/obs/obs_{日期}_{主题}.py` 或 `bt_{日期}_{主题}.py`。

脚本必须满足六条形式要求（每条都可机械检查）：

| # | 要求 | 为什么（可验证的后果） |
|---|---|---|
| 1 | 样本区间写成顶部显式常量（`START = "2024-01-01"`），输出首行打印区间与样本量 | 区间混入 2025-08 前数据会有选择偏差（当时每日只覆盖约 2530 只，非全市场） |
| 2 | 涨跌幅用 `change_pct` 累乘重建，不用 `close` 相除 | `close` 不复权；除权票 60 日跌幅可虚高 31.8 个百分点 |
| 3 | 所有入场特征用**入场日可见**的量；未来数据一律不进特征列 | 特征列混入未来量，回测收益直接虚高且无法察觉 |
| 4 | 逐日横截面构造对照基准（同日全市场同期收益），不跨期比 | 跨期比会把 beta 当成 alpha；2024Q3 与 2026Q2 的市场方向完全相反 |
| 5 | 连续计数用「非条件日切段」，不累加 | 累加算的是历史总量，不是当前连续段长 |
| 6 | 剔除 ST / 北交所 / 上市不满 60 交易日 / 低价（<3 元） | ST 限幅口径失真；次新股污染；低价股博弈性质不同 |

### 第 2 步 · Verification：步进式检验

按季度切 fold，**训练窗只用于选，验证窗才是成绩单**。骨架（可直接复制改）：

```python
FOLDS = 按季度分组(rows)                       # 每 fold ≥200 条样本
for i in range(3, len(FOLDS)):
    train, valid = FOLDS[i-3:i], FOLDS[i]      # 训练 3 个季度，验证下一季度
    best = argmax_均值(train, 全部候选组合)      # 只读训练窗
    record(valid_表现(best), valid内排名(best))  # 打开验证窗
```

同时必须做**不用选择的对照**：固定用某条组合，跑完所有验证窗，报均值与最差 fold。
因为选择无效时，唯一可用的是"先验设定、固定使用"的那条。

### 第 3 步 · 定级：按三条判据决定去向

| 判据 | 通过线 | 去向 |
|---|---|---|
| **跨 fold 符号一致性** | ≥7/10 个 fold 同号 | 必要条件，不满足直接留在 obs 层 |
| **最差 fold 不失控** | 最差单 fold 中位亏损 ≥ −8% | 满足才可作**执行规则** |
| **验证窗不劣于对照** | 与固定使用同一组合的验证均值差 ≥ 0 | 满足才可作**优选规则** |

三条全过的 → 写成规则（skill 章节 / `calibration_queue` 候选，后者仍须用户批准）。
过 1~2 条的 → 记为「有线索、未定型」，留在 obs，标注缺哪个判据。
一条不过 → 在 obs 里标「已否证」，附否证数据。

## 三、报告必须给的五个数（缺一即不完整）

用户口径（2026-11-05 定）：目标是抓到区间涨幅最大的票，**胜率与 T+N 平均涨幅不作为评价标准**。

| # | 数 | 说明 |
|---|---|---|
| 1 | **区间最大涨幅分布** | 中位 / P90 / P99 —— 右尾有多厚 |
| 2 | **先套深度** | 买入后 10 日 / 20 日内最深浮亏的中位 —— 能不能拿住 |
| 3 | **赔率** | 中位最大涨幅 / 中位先套深度 |
| 4 | **赚 30%+ 与亏 10%+ 占比** | 两端概率，右尾策略靠这个算期望 |
| 5 | **fold 一致性 + 最差 fold** | 上面三条判据的原始读数 |

**均值单列不算结论**：右尾分布下均值被少数样本主导，中位与分位数才是可用读数。

## 四、四条铁律（每条都有实测支撑）

1. **规则先验设定、固定使用**。不在历史段上挑"哪条最好"，挑优迁移率 0/7。
2. **出场规则按入场口径配对**。跌破 MA5 在「深跌入场」上 10/10 fold 为正（最稳防守）；在「已涨大牛股」上把捕获率从 54% 砍到 0.1%。同一规则跨口径会反向。
3. **样本量先看再下结论**。n<100 的格子只当线索；n<20 一律写「样本不足」，不硬测。
4. **结论必须带边界**。写明市场（A 股）、区间、含什么特殊阶段（如 924 反弹）。跨市场不自动成立。
