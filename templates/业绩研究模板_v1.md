# 业绩研究模板 v1（2026-10-29 建 · 来源：外部评估 3/10 处方）

> 适用：任何"某公司/某行业业绩趋势"类研究请求。**七字段缺一即不合格**，研究不足时明写"不足以判断"，禁空话补齐。
> 本模板只约束**研究结论交付**，不约束提问数量（问题数由证据决定）。

## 必答骨架（缺一即不合格）

| 字段 | 要求 | 反例（不合格） |
|---|---|---|
| ① 结论 | 一句话，含方向+幅度+期限 | "业绩向好" |
| ② 证据 | 每条带**来源+发布日期**（财报期/公告日/数据日） | "据公开信息" |
| ③ 推理 | 因果链：什么业务驱动 → 收入/毛利率/费用/现金流各自怎么变 → 为什么 | "基本面改善" |
| ④ 反证 | 什么证据出现即推翻本结论；已考虑了哪些反方理由 | 无 |
| ⑤ 预测 | **数字+期限**：指标、区间、截止报告期 | "下季度会更好" |
| ⑥ 置信度 | 高/中/低 + 依据（证据密度×机制清晰度） | 无 |
| ⑦ 验证 | 机械可判的验证指标 + 到期日（披露日/数据日） | "持续跟踪" |

## 定性四选一（增长性质判断，放①内）

`持续性改善`（供需+格局+盈利质量同向）/ `周期反弹`（价格或利用率驱动，有顶）/ `一次性因素`（非经/口径/基数）/ `会计表象`（现金流与利润背离）

## 交易转化段（可选，触发才填）

触发条件 / 失效条件 / 预期收益风险比 / 仓位上限。**研究正确≠该交易**：需过市场定价核查（隐含预期了多少）+ 择时闸（RISK_OFF 一律不转交易，只入候选）。

## 产业级研究补充字段（行业/产业链请求时加答，公司级可选）

| 字段 | 要求 |
|---|---|
| 产业链位置 | 上/中/下游+成本与需求传导机制（什么变量决定行业利润） |
| 生命周期阶段 | 导入/成长/成熟出清/周期反转/衰退——阶段决定估值法和参与方式 |
| 供需四件套现状 | 供给（产能/资本开支）、需求（排产/订单）、库存、价格（加工费/售价）各自方向，证据带日期 |
| 需求拉动 vs 供给收缩 | 周期反转必答：哪边驱动决定持续性；不足则明写"不足以判断" |

## 与账本的接口

- 预测字段⑤+⑦ → `h_ledger.create()` 立账，HID 编号 `H-ER<日期><序号>`（ER=Earnings Research）
- 到期 → `--settle` 机械评分：命中区间=SUPPORTED / 出区间=REFUTED / 披露不足=INCONCLUSIVE
- 结算后 7 日内 case_builder 归因，错因四分类：数据错 / 因果错 / 期限错 / 定价错

## 盲测纪律（验收用，task #278）

历史案例回测时**必须隐藏预测时点之后的一切数据**（含后见之明的行业新闻），只允许当时可得的报告与数据；评分基准=线性外推+一致预期，双基准。
