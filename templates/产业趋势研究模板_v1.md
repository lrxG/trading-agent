# 产业趋势研究模板 v1（2026-11-05 建 · 起因：用户两次点名"输出产业趋势研究"，无模板导致输出跑偏）

> 适用：任何"产业趋势研究"类请求（单产业或多产业横评）。**每主线七字段缺一即不合格**，证据不足时明写"不足以判断"，禁用链图谱代替研究报告。
> 链图谱（data_industry_chain）只是**证据源之一**，不是交付物；交付物是本模板结构的成文报告。
>
> ⚠️ **本文件是字段纪律规范，不是成文骨架。** 实际写报告请照 `templates/产业趋势研究模板_v2.md`（填充式骨架：L0 报头 → 执行摘要 → 总纲排序 → 逐主线七字段 → 横评矩阵 → 证伪线总表 → 归档汇总 → 操作映射 → 账本 → 数据缺口 → 11 条自检门）。两份配合用。

## 输出结构（三段固定）

```
一、总纲：主线排序表（多主线时必做）
二、逐主线七字段骨架
三、观察池归档 + 操作映射（闸 OFF 时写明"零动作"）
```

## 一、总纲排序表（固定列）

| 主线 | 生命周期阶段 | 驱动性质 | 当前状态一句话 |
|---|---|---|---|
| … | 导入/成长/成熟出清/周期反转/衰退 | 业绩·事件·商品·政策·资金 | … |

排序原则：按**距验证事件的远近**排（最近的验证点排最前），不按热度排。

## 二、逐主线七字段（缺一即不合格）

| 字段 | 要求 | 反例（不合格） |
|---|---|---|
| ① 结论 | 一句话：方向+幅度+期限 | "长期看好" |
| ② 证据 | 每条带**来源+日期**（产业统计/公告日/商品报价日/资金流日期） | "行业景气度高" |
| ③ 推理 | 产业因果链：什么变量驱动 → 供需/价格/订单怎么传导 → 为什么现在 | "赛道好" |
| ④ 反证 | 什么证据出现即推翻；已考虑的反方理由 | 无 |
| ⑤ 预测 | **数字+期限**：可量化指标（订单额/价格区间/资金流方向/板块涨幅带） | "会继续涨" |
| ⑥ 置信度 | 高/中/低 + 依据（证据密度×机制清晰度×样本量） | 无 |
| ⑦ 验证 | 机械可判的验证指标 + 到期日（数据发布日/公告窗口） | "持续跟踪" |

**产业链位置字段**（引用链图谱时必须压成一句）：上/中/下游 + 什么变量决定该环节利润 + 链上代表标的 ≤8 家。

## 三、观察池归档（固定格式）

每主线产出归入四档之一：
- **兑现档**：验证事件可查证（招标/订单/数据发布），等触发
- **预期档**：情绪/主题段，需配机械兑付卖出线（兑付点+减半+清仓日）
- **政策档**：政策点名但传导链未验证，只记录不归档
- **出列**：证据不支持主线定性

## 与账本的接口

- 主线预测字段⑤+⑦ → `h_ledger.create()` 立账，HID 编号 `H-IT<日期><序号>`（IT=Industry Trend）
- 多主线报告每条主线至少立 1 个 H 或明写"本主线无可立账预测"（禁静默跳过）
- 到期 `--settle` 机械结算；结算后 case_builder 归因

## 纪律

1. 闸 OFF 时报告尾部必须写"研究仓内容，零实盘动作"，禁给买点。
2. 单主线证据 <3 条带日期的硬证据 → 该主线降级为"观察"，不进总纲排序。
3. 禁止把链图谱成员列表当研究结论——图谱回答"谁在链上"，报告回答"趋势到哪了、怎么验证"。
