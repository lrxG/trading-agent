# 盘前预案模板 · v2（7 节定稿）

> 定稿依据：2026-10-29 用户确认。原则：服务于交易决策与收盘验收，不追求信息覆盖率。
> 逐节填充规则如下，冗余内容（纯数据罗列、无传导路径的外围琐闻、与正文重复的附录）一律不写。

## L0 决策摘要

- **一句话结论**：今日唯一动作 / 不动作，一句话说死。
- 定调（当日市场性质判定，一句）。
- 持仓一览（含来源标注：决策链 / MANUAL_OVERRIDE）。
- 不做清单（负向纪律，≥1 条）。
- 候选 / 预埋（OFF 期写「无+原因」）。
- **风险口径（三分法，禁止混用）**：
  - 当前持仓风险 = 现有持仓的单日最大计划亏损（按持仓资产历史最大单日波动计）
  - 新交易风险预算 = 今日新开仓的预设亏损上限（无新仓则为 0）
  - 硬风控 = 以系统风控规则为准（params.json 熔断/仓位上限），预案不得覆盖
- 今日 H 清单（编号索引，正文给完整字段）。

## ① 隔夜外围（只写有当日传导路径的，≤4 条）

每条格式：资产/事件 → 数据 → 对 A股传导 → 出口（影响哪个持仓/候选/判定）。
无传导路径的（外交琐闻、无映射的行情点位）不写。

## ② 昨日复盘

必含四件（H 验证标准的数据底座）：宽度（涨跌家数/涨占比）、涨跌停家数、新高新低结构（5/20/250 日）、择时状态与计数。
相关板块细节只写与主线光谱相关的。不做全文数据罗列。

## ③ 主线与板块（光谱+分级合一）

每条主线一行：主线 / 状态（含 5 日主力资金方向） / 今日看什么 → 出口 / 参与条件 / **证伪条件**。
分级标注：⭐预埋（转 ON 后候选）/ ⭐观察 / ⚠️回避。

## ④ 企业事件（严格收窄）

只写**会改变持仓决策、候选股预期或当日交易条件**的公告、业绩、政策事件。
每条带出口。与 ① 的区别：①是市场/宏观传导，④是标的/规则直接作用。纯资讯琐闻不写。

## ⑤ 情景（操作定死）

2~3 个情景，每格：预判 → 操作（收盘前不许改）。
情景必须覆盖「最可能 / 次可能 / 尾部风险」三格。

## ⑥ 假设与盲区（H 编号 = 收盘验收机制）

每个 H 五字段齐全，缺一不算：
| 编号 | 预测内容 | 验证指标 | 有效时间窗 | 失效条件 |
数据缺口写在本节末尾（标注「不臆断」），不单开附录节。

## 已删除（原模板冗余）

- L2 附录（与正文重复；收盘对账依赖 H 编号+账本，不依赖附录）
- 隔夜外围中的无传导条目
- 与主线光谱重复的独立板块分级表

## 附：消息面分级规范（2026-10-30 增 · 来源：信息能力升级方案）

预案消息面每条必须标注可信度级别：
- **A**=原始事实（交易所公告/公司披露/政府文件原文）
- **B**=权威报道（新华社/证券时报/财联社/上证报等主流媒体）
- **C**=市场信息（券商观点/产业链调研/传闻——只触发调查，不当事实用）
- **D**=情绪线索（雪球/股吧/热榜——只看扩散不看方向）

并按事件影响跟踪五维登记：影响方向 / 影响对象 / 影响时间 / 是否已定价 / 后续验证点（验证点直接生成 H 假设）。
同一事件多来源只算一份证据（事件 ID 归并），转载不增加证据强度。
