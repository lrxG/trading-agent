> **来源**：旧系统归档包 `炒股智能体_旧包_20261008/skills/industry-track/OUTPUT-TEMPLATE.md` + `SKILL.md` 四铁律（2026-10-08 归档，2026-11-05 用户令移植）。
> **v1（字段纪律）/ v2（成文骨架）自本版起作废停用**——用户定性 v2 风格为"作文"，旧版例外制简报为准。
> **读者 = 决策层（用户）**：只出可验证的产业判断（状态 + 条件 + 证伪）。**不出交易指令**——埋伏位/低吸/追高/减仓一律不写，是否配置由交易系统决定。
> **按信息量，不设行数上限；无变化不出行。**
> **交付形式（2026-11-05 用户铁律）**：正文直接输出到对话；文件仅留痕（data/generated/，git 不追踪）。

## 四条铁律（最高优先级，承接旧 SKILL.md）

1. **产业景气 ≠ 股票机会**：产业趋势形成但 A 股未涨才是埋伏机会；A 股已大涨 ≠ 产业趋势开始（资金炒 ≠ 趋势）。
2. **产业趋势 ≠ 市场情绪**：海外事件必须拆链验证（事件→是否改变基本面→需求→格局→中国环节→A 股是否只是情绪）。
3. **必须比较「产业现实 vs 市场预期」**（预期差是核心）。
4. **不直接生成交易动作**：只输出可验证的产业判断，不输出买卖时点。
5. ★**暴露度前置**：任何"产业→标的"映射，先取该公司该业务收入占比。**<20% 禁称"龙头/核心受益"，只标"标签受益（弹性被稀释）"**；占比 0 标"负受益"。旧实证（电子布链）：宏和 >95%/业绩 +334% 严格单调，而市场把占比 3.3% 的中材当主角定价（涨 170%）。
6. ★**斜率比按业务加权**：兑现度计算时产业信号涨幅须乘以业务收入占比；裸价比裸价会把标签溢价误判成趋势兑现（旧实证：中材透支 44 倍 vs 宏和 0.94x 同步——同一信号载体选错，透支差 47 倍）。

## 三条输出铁律

1. **【A股关注】是唯一必读块，置顶**。其余全是它的支撑证据。
2. **例外制**：零异常一行字、无变化不出行、样板句不写。面板只报例外。
3. **无环境锚的兑现度数字一律不作结论**：同一斜率比，退潮期 = 透支、主升期 = 未兑现。

## 结构总览（段序固定）

```
【环境锚】            ← 2 行
【A股关注】           ← 唯一必读块，置顶，按剩余预期差从大到小
单候选详版            ← 点名才出
【变化】              ← 只列与上次不同的增量
【兑现度】            ← 零异常 = 1 行
【机制面板】          ← 1–3 行，只报例外（含该跑没跑的）
📋 经验参考           ← ≤3 条，只报新触发/被验证的
```

## 各块判据

**【A股关注】**每条一行给全四件：
```
板块+代表环节/龙头 | 现状一句话（兑现状态+预期阶段）| 升级/退出条件（含下一验证点）；置信<60% 标 ⚠️无战绩
```
- 兑现状态（斜率比结论）：`透支(≥3x)` / `同步(≈0.9x)` / `滞后(0~0.5x)` / `逆向(<0)` / `未兑现窗口`；斜率比管线未迁移期间用定性标注并声明。
- 预期阶段（五段）：`①形成 / ②发酵 / ③主升 / ④兑现 / ⑤证伪`。
- 出名单的标 `移除`（一句话给理由）。

**【变化】**`[符号][候选] 数字 → 意味 → 验证点`。

**【兑现度】**真异常（≥3x 或逆向）才逐行展开，其余一行汇总。

**多时间点对比**（要求对比时用）：方向+幅度+加速度=趋势三要素；强度六档色阶 `⚪观察 → 🟡关注 → 🟠强化 → 🔴强势 → 🟣钝化⚠️ → ⚫退潮`。
