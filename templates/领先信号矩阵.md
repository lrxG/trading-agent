# 领先信号矩阵（实物世界 · 每日必扫）

> **定位**：盘面信号是「已经发生」的，产业与商品数据是「先发生」的。本表每天过一遍，**不等涨了再问为什么**。
> **铁律两条**：①商品 / 产业数据月度异动 ±5% 级 → 强制查 A 股映射；②商品与股价互相领先，**谁动都查另一个**。
> **消费方**：盘前预案 ① 隔夜外围 · 产业趋势研究进料 · 收盘体检 `close_audit.py` A 段归因时的旁证。

## 二、通道边界（本机实测）

- **westock 期货通道只覆盖外盘**（LME / CME / CBOT）。国内商品期货（多晶硅 / 碳酸锂 / 工业硅）**不在通道内**。
- 外盘腿 → 通道自动化扫描；国内腿 → 生意社日更 + 定向检索，固定清单逐项过，不随机抽查。

## 三、扫描结果的三种处置

| 扫描结果 | 动作 |
| --- | --- |
| 某品种触发阈值 | 当日查 A 股映射与传导链长度，写进预案 ① 或研究报告的进料；**不写"关注"，写具体标的环节与验证时点** |
| 全部平静 | 一行字写「今日实物世界无增量」，不占篇幅 |
| 数据取不到 | 写 `NO_DATA` + 缺哪个源，不省略、不用旧值顶替 |

## 四、与盘面的优先级

商品先动、股价后动时，商品信号优先（这是本表存在的理由）。
股价先动、商品没动时，按**事件驱动 / 情绪**定性，不给「产业拐点」的结论——产业拐点必须有价格或排产数据支撑。
