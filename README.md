# trading-agent · A 股交易智能体（完整体系 · 开源版）

> **这是一套完整的 A 股交易智能体**：把本仓库放入 WorkBuddy 工作区，
> 平台智能体读入内核与知识后，即具备盘前预案 / 盘中扫描 / 盘后复盘 /
> 步进回测 / 事件研究的完整炒股能力——以及一套让它**不亏在纪律上**的门禁体系。
> **不构成任何投资建议**；回测结论均为历史统计证据，见文末免责声明。

## 一、它是什么：智能体的"身体 + 记忆 + 纪律"

WorkBuddy 平台提供智能模型（灵魂），本仓库提供剩下的一切：

| 组成 | 位置 | 作用 |
|---|---|---|
| **内核（行为真源）** | `AGENT.md` | 主循环、三锁（信息截断/决策冻结/机械判定）、七入口 I1~I7、三问准入、风控权限——智能体"怎么思考和行动"的唯一来源 |
| **平台注入入口** | `CODEBUDDY.md` | WorkBuddy 每会话自动注入；只放指针不放内容（防第二真源） |
| **能力（手）** | `tools/` | 盘前/盘中/回测/事件研究/信息面/学习闭环，全部可执行 |
| **门禁（刹车）** | `tools/fs/` | 落点封闭、写点登记、骨架台账、防假 LIVE——机器可判的纪律 |
| **知识（学过的课）** | `data/knowledge/`（入库）+ `PLAYBOOK` · `data/research/event_effect/base.json`（**运行后本地生成**） | 预案结构基线、盘感卡、战法台账、事件效应先验（全部带溯源与验证状态） |
| **记忆（经历）** | `memory/` + `.workbuddy/memory/`（**均不入库，本地生成**） | 认知状态、持仓真相源、每日复盘、事故复盘 |
| **数据管道** | `data/raw/` + westock CLI | 行情/涨停池/板块/资金流/公告/快讯/热搜/事件日历/外盘期货 |

## 二、新机器冷启动（六步）

**前置**：WorkBuddy、Python 3.13+、[westock CLI](https://gitee.com/)（行情数据通道）、可选通达信本地服务。

**环境变量（可选，全部有兜底，不设也能跑）**：

| 变量 | 作用 | 未设置时 |
|---|---|---|
| `OLD_SYSTEM_ROOT` | 旧系统只读参考源目录（部分研究件回看历史数据/事件库时用） | 默认 `~/炒股智能体_旧包_20261008`；目录不存在则相关读取自动降级为 UNAVAILABLE，不报错 |
| `REQUESTS_CA_BUNDLE` | akshare 类采集（股东户数）所需 CA 证书路径 | 用系统默认证书 |

> 仓库内**不硬编码任何本机绝对路径**；Python 解释器一律 `sys.executable`，旧系统引用一律走上述变量。

1. **放入工作区**：本仓库整个目录放进 WorkBuddy 工作区根。
   平台自动注入 `CODEBUDDY.md` → 智能体第一动作即读 `AGENT.md` 完成内核装载。
2. **初始化状态骨架（新机器必做）**：`python tools/fs/init_state.py --date <today>`
   ——仓库只分发系统本体，**不含任何个人记忆与运行态账本**（见 `.gitignore`）。
   本步幂等生成 `data/state/` 下 10 个骨架文件；其中 `account.json` 的 `capital=0`
   会让 C5 资金闸拒绝开仓（fail-closed，设计如此），填真实权益后放行。
3. **对齐时钟与账本**：让智能体跑 `python tools/fs/wakeup.py`——看游标、母链就绪度、
   三项自检（上一日是否结账/未处理 FAIL/STALL）；游标落后则 `wakeup.py --wake <today>`。
4. **数据自拉**（仓库**不含采集数据**——日链每天自动采，历史用回填工具）：
   - 日常数据：跑日链 `daily_pipeline.py` 即自动采集当日全量（行情/涨停池/公告/资金流/竞价）
   - 历史底座（回测需要 2024 起的 klines/涨停池/资金流）：按 `docs/数据源.md` 跑回填工具
     —— `backfill_klines_tq.py`（需通达信本地）/ `lhb_backfill.py` / `fetch_fundflow.py` /
     `fetch_news.py --notice-pool --execute`；环境历史指标 `env_recalc.py` 一键重算
   - 口径契约在 `docs/RAW-INGEST-CONTRACT.md`，勿自造口径
5. **自检全绿**：`landing.py` / `registry.py --verify` / `wakeup.py --acceptance` /
   各件 `--selftest`（replay 28 项、intraday 31 项、预案 10 项、信息面 8 项……）。
6. **开始运转**：进入下节日常循环。首次使用建议先只跑回测与研究（不接实盘），
   直到跑过一轮回测、读过本地生成的 `PLAYBOOK.md` 并理解纪律条款。

## 三、日常循环（智能体的每个交易日）

| 时段 | 命令 | 产出 |
|---|---|---|
| 盘前 09:00 | `info_feeder.py --date <today> --incremental` → `premarket_card.py --date <today>` | 信息面速览（快讯/热搜红灯/事件日历）→ L0 决策层+①~⑫预案（候选≤3，五要素：触发区/证伪线/动作） |
| 盘中 | `intraday_scan.py --execute` | 发现流水（append）+ 盘中作战卡（实时定调/主线光谱/池内异动/状态迁移） |
| 盘后 | `daily_pipeline.py`（日链）/ `eod_review.py` | 快照落库、结算、游标推进 |
| 周度 | `learning/learn_pipeline.py --weekly` | 回放→Case→观察→需求→5 指标（学习不占实盘时间，用户令） |
| 研究 | `replay.py run/audit/compare` + `event_study.py run` | 策略对照实验 / 事件效应复核 → `PLAYBOOK.md` |

## 四、回测引擎：四层分离 + 研究管线

```
World Feed（≤D 冻结快照，版本钉扎）
   ↓
Policy（纯函数策略，mech_v0~v9；agent 步进模式保留）
   ↓
Executor（T+1 开盘 / 涨跌停拒单 / 缺口条件单 / −8% 兜底 / 成本——全策略共用）
   ↓
Audit（逐笔归因 · 闸门反事实 · 环境档分组 CI，n<20 强制 INSUFFICIENT）
```

- **compare 硬闸**：数据/执行器/本金版本不一致 → 拒绝比较
- **行情×策略矩阵**（当前）：强势→弱转强 +4.73%/笔；震荡/退潮→深超跌×普涨反弹 +1.5~2.4%/笔；
  追高结构全域负（详见 `data/research/replay/PLAYBOOK.md`）
- **事件效应先验**：61,980 事件包（F7）+ 18,190 事件包新窗口复核——
  风险公告 −2.9%、情绪票遇利空 −3.6% vs 冷票 −0.6%、增持/回购/业绩类 CI 跨零
  （**不是所有消息都影响股价**）

## 五、门禁：为什么这台机器不会"跑飞"

本体系最重要的一部分不是策略，是**纪律的机械化**：

1. **三锁**：信息截断（取数≤游标日）· 决策冻结（下注前定格判据）· 机械判定（禁文字复盘改判）
2. **落点封闭**：知识/结论/研究只进 5 落点+5 豁免，`landing.py` 机械判，第 6 类不存在
3. **写点登记**：任何持久化写入必须登记（`WRITE_ENTRYPOINTS`），未登记 = 违例
4. **升版走迁移件**：改骨架 = 显式动作，台账可追溯（`data/state/migrations/`）
5. **硬风控独立**：熔断/仓位上限只存 `params.json`，AI 无权自改（候选→验证→用户批准）
6. **学习不占实盘时间**：自我进化全部走历史回测（2026-10-23 用户令）

## 八b、可视化面板（`tools/dashboard/`）

**为什么有它**：对话式问答不适合盘中决策——一条结论刷屏过去就找不到了，
读数也不能一直盯着。面板把「每天的判断」钉成一屏，改一次数据源整屏跟着变。

```bash
python tools/dashboard/server.py --open          # 或双击 tools/dashboard/start.bat
python tools/dashboard/server.py --port 8771 --warm
```

打开 `http://127.0.0.1:8770/`。**纯标准库 + 原生 canvas，无 CDN、无外网依赖。**

| 区域 | 内容 | 真源 |
|---|---|---|
| 顶栏 | 环境档/仓位上限 · 涨跌比 · 中位/等权 · 封板数 · 首板占比 · 2板+ · 炸板率 · 成交额 | `env_metrics.json` + `daily_quote.csv` + `limit_up.csv` |
| 左栏 | 用户实盘持仓（成本/浮盈/纪律线距离条）· 自选（可搜索加票）· 封板梯队 | `memory/state/user_positions.md` |
| 中栏 | K线 + MA5/10/20/60 + 成本线 + 成交额 · 全市场涨跌分布 · 板块资金流 | `klines.csv` · `sector_ranking.csv` |
| 右栏 | 今日一句话判断 · 连板结构（首板占比 3 日对比）· 族温度计 · 数据缺口 | `brain_state.md` · `zibei_thermo.py` |

**两条硬规矩（写在代码里，别绕过）**：

1. **量能一律用成交额，禁用 `volume`** —— `klines.csv` 的 volume 单位三段跳
   （2024 比对 0.10 / 2025-09~2026-09-30 是「手」≈100 / 2026-10-08 起是「股」≈1）。
   跨 2026-10-08 的表观「放量 69 倍」实为「缩量 43%」。详见 `trade-rules` §一d.11 第 4 条。
2. **面板只读**：不写任何文件、不落缓存、不改参数，因此不影响落点封闭纪律。
   解析失败一律显式标「解析告警」，不静默补 0。

**盘中模式**：`?mode=int` 或右上「盘中」按钮，切到最近一份 `data/raw/intraday/<date>/scan_*.csv` 截面
（宽度/封板数/连板梯度）。**没有逐分钟行情，所以不画分时曲线**——raw 里没有，不凭空造。

## 九、研究纪律（宪法条款）

1. 一次只验证一个主要改进；训练区/OOS 分离，禁拿 OOS 反复调参
2. 每道闸/每个变体必须证明独立增益，否则不采纳（**否决也归档**，负知识防重复踩坑）
3. 知识必须转成可验证假设；未经 verify 统计 + 用户批准不得修改生产参数
4. 四态区分：逻辑已实现 / 历史回测验证 / 样本外验证 / 实盘验证——不得混为一谈
5. 资料管线：外部战法/资料只当"线索"，必须翻译成机械口径→对照回测→分级裁决后才能吸收
6. 增量只出新、快照可回溯、口径唯一（涨停数等关键指标禁双口径）
